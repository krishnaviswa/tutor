# Catalog

Machine-readable contract for TutorOS. Regenerated by `python scripts/build_catalog.py` from `tutor-platform-demo.html` (`S`, `WHY`, `TEMPLATES`) plus planned APIs in that script.

If this catalog disagrees with the demo, rebuild it. Do not invent screen ids.

- `screens.json` — 47 screens (closed set) + own/who/why/how/when + swimlane `roles`
- `modules.json` — A1–G5
- `flows.json` — template tours t1–t6 with per-step role/stage
- `apis.json` — planned `/api/v1` paths
- `entities.json` — spine vs later
- `ports.json` — vendor adapters
- `env.json` — names mirrored in `.env.example`
- `embed.js` — loaded by `tutor-platform-architecture.html`
