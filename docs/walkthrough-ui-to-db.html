Follow any other button

  1. Find the api("/api/v1/...") call in frontend/components/**.
  2. Search backend/app/api/v1 for the matching @router.<verb>("...").
  3. Read the signature: body model, require_roles, get_db.
  4. Follow the call into services/<topic>.py, then to the tables in models/tables.py.
  5. Run the backend and open http://127.0.0.1:8000/docs to try any endpoint by hand.
