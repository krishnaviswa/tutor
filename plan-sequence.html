Build order, both languages

Left column is what a tutor, student, parent, or owner can do. Right column is the stack change. Do not skip. If pytest goes red, stop.

Already built (001 + 002)

Functional

Humans can click 47 demo screens and the architecture map. Operators can switch three seeded workspaces and five roles via OTP stub, persist roster/cohort, write a session record, see timeline events, open parent hub (some children empty), see quota warn/block on owner/subscription.

Technical

Catalog JSON + architecture HTML (001). FastAPI /api/v1, SQLAlchemy spine + meters, SQLite file, 33 sim APIs, mock ports, pytest isolation/record/quotas/parent. Next.js not built. 51 APIs still planned. All screens empty.

Tasks: done — do not rewrite

P0 — Close 002

Functional

Leads accept that the spine behaves as specified. Teaching write still becomes a ledger event. Tenants stay isolated.

Technical

Run backend pytest. Converge ACs to tests. Mark 002 Accepted in README/spec. No new tables yet.

Tasks: T0.1 T0.2 T0.3

P1 — Environment

Functional

Any engineer can boot the API locally. Optional Postgres for people who want production-shaped SQL. Node ready for the later UI. Hosting is still not the goal.

Technical

pip + uvicorn :8000. docker compose up -d postgres optional. DATABASE_URL documented. node -v 20+. Secrets never committed. Providers mock.

Tasks: T1.1 T1.2 T1.3

P2 — Database

Functional

The product can remember practice, homework, doubts, chats, invoices, automation — still per workspace, still not a syllabus database.

Technical

Add 17 catalog-later tables with workspace_id. Isolation tests A vs B for each. create_all/seed expansion. No biology_chapters.

Tasks: T2.1–T2.6

P3 — Backend (remaining catalog APIs)

Functional

A teacher can attach a mock video link; a student joins through the platform (attendance is ours). Live console, library, assignments, question bank, practice loop, tests, doubts, messages, announcements, dashboards, billing (mock pay), templates, automation, integrations (mock connect) all exist as APIs.

Technical

Implement 51 planned /api/v1 paths. Replace 002 empty stubs (attempts, threads, invoices, reports) with real reads after tables exist. Timeline first; Notify mock; QuotaGuard on paid sends. live_calls == 0.

Tasks: T3.1–T3.21 (critical: T3.2, T3.7–T3.9, T3.16, T3.21)

P4 — Frontend

Functional

Humans use the same 47 screen ids in a Next.js app. Exam-prep faculty still does not go through staff-login. Demo look is the gold until a screen is wired. Parent sees real child rows when those modules exist.

Technical

Next.js 15 App Router. One route per catalog route. Wire 002-backed screens first, then B live/content, C practice, D comms, E progress, F business, G config. No invented pages. CORS to FastAPI.

Tasks: T4.1–T4.9
