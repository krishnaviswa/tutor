# Tutor operating loop — best-of filtered for this faculty

This file does **not** rewrite those strategies. It adds **timing** and a **keep / refuse** filter so “best of all” is a solo-tutor loop, not a mashup of nine companies.

Constraint this loop assumes: one Biology faculty, PPT 2–3 days per Priority-1 topic, YouTube + online classes, long-term coaching brand. Closest spine: **coaching OS + visual library + practice artefact**. Not a school OS.

## Expert score (honest)

The comparison files are a **good operating map**, not a shippable product spec.

| What | Score | Why |
|---|---|---|
| Separating four spines (school OS / coaching OS / practice OS / visual library) | **9/10** | Main insight. Mixing them is how clones fail. |
| Steal-sheet *behaviours* (DPP same day, WAVE micro-activity, mentor ≠ lecturer) | **8/10** | Transferable *jobs*, not logos. |
| Pair scores (1–5 in the HTML) | **6/10** | Expert ordinals. SKU drift and ±1 error are real. Not telemetry. |
| “Ideal stack” as one app with all 10 layers | **3/10 as implementation** | Multi-team company. One faculty role cannot be LEAD coordinator + WAVE TAs + Pathshala doubt counters. |
| Fit to this tutor (solo NEET Biology, PPT 2–3 days, YouTube + classes) | **7/10 if filtered; 2/10 if copied raw** | The NEET file already has the right production unit: **one Priority-1 topic = content package**, not one cinematic PPT. |

**How effective “best of all” can be here:** high on *which loop to run and what not to build*; low on *recreating WAVE, Toppr ML, or LEAD tablets*. Effectiveness comes from filtering donors through one teacher, Biology, NEET UG 2026 syllabus, and production time.

## Filter that stays in force

From the comparison closing rules. Do not drop these when copying a feature:

1. **Layer four spines.** School OS, coaching OS, practice OS, and visual library can share a login later. They cannot share one faculty role now.
2. **Star faculty is not the homework policeman.** Mentors / a backlog slot chase skipped tests. The lecture does not.
3. **Live without a same-day practice artefact is webinar theatre.** DPP (or equivalent) on the same calendar day.
4. **Analytics without a remedial action is a PDF nobody uses.** A miss must become a tagged item, a DPP-solve clip, or a mentor backlog — not only a score.
5. **WhatsApp / Telegram is overflow**, never the system of record for notes, tests, or doubts.

Copy the **behaviour**, not the **org**.

## Keep vs refuse (this tutor)

### Keep — high transfer to a solo or small batch

| Donor | Behaviour to copy | What it becomes for you |
|---|---|---|
| BYJU’S TLA | Designed visual story + three difficulty lanes after the same lesson | Priority-1 PPT + Warm-up / Sprint / Race lanes on the **student worksheet**. Not a TLA studio. |
| PW | Lecture-wise notes + DPP + same-day DPP *solve* | Notes aligned to the lecture; 10–15 items that must be solved the same day; optional 15–20 min DPP-solve video or class. Not an 8-hour Pathshala counter. |
| Adda247 / PW AITS | Weekly paper + *analysis class*, not a silent rank | Chapter test or PYQ set **plus** a short analysis (already planned as the PYQ video / analysis class). |
| Vedantu WAVE (lite) | Something every few minutes in live | Poll, MCQ, or board step — **only when you teach live**. No parallel TA swarm. |
| Toppr (lite) | Flag slow-but-correct vs concept-wrong | No ML engine. Tag each missed item on the worksheet **key**. |
| Unacademy Iconic / upGrad Jeet (lite) | Booked 8–10 min on *skipped tests*, not re-teaching | Only after a **named paid cohort** exists. YouTube-only viewers do not get this until they join a batch. |

### Refuse for now — wrong spine or org you do not have

- LEAD school OS (timetable, attendance, remedial roster, coordinator observation)
- Extramarks scan-grade / paper factory and school-to-home LPT as a product
- Unacademy full go-live dashboard (chroma support, gated raise-hand, incentive/penalty OS)
- PW Pathshala 8-hour subject-wise doubt counters
- Parent attendance OS
- Offline SD / tablet lesson packs
- Hybrid two-teacher hall (studio star + in-room expert)

Those remain useful as **donors to study**, not as this year’s build.

## Map to the existing content package

The NEET file already defines one Priority-1 topic as **8–10 assets**, not one PPT. Example given there (TCA Cycle): long YouTube, 3 Shorts, PYQ video, revision video, class PPT, student worksheet, chapter test.

This loop only adds **when** those assets fire. It does not add new strategy.

| Existing asset (NEET plan) | When it fires | Donor timing logic |
|---|---|---|
| Class PPT + long YouTube | Day of publish / class | Visual library (TLA-style designed module) |
| Student worksheet: Warm-up 4 / Sprint 8 / Race 4 | Same session / same day as the lesson | TLA lanes; Toppr tags on the **key** (time-sink vs misconception) |
| Same-day DPP (10–15 items; may overlap the worksheet or sit beside it) | **Same calendar day** as the lecture | PW DPP as a must-solve artefact |
| 15–20 min DPP-solve (live class or short video) | Same evening if possible | PW live DPP (kills solution-video backlog) |
| 3 Shorts | Same production window; publish around the long video | Packaging, not a platform steal |
| PYQ video + chapter test | **Same week** as the topic, not months later | Adda247 Sunday test + faculty analysis; PW AITS ritual at tutor scale |
| Revision video (5 minutes) | End of that week or as a playlist closer | Recovery asset; not a substitute for DPP |
| Logged doubts (sheet / Classroom / Notion) | After class and overnight | DOC *job* (photo/text in); WhatsApp only as overflow |
| Fortnight 8-min backlog call | Paid cohort only | Iconic / Jeet: skipped DPPs/tests, not a second lecture |

**Priority 2 and 3:** skip cinematic visual and WAVE production. They still get a **same-day practice artefact**. Live without DPP remains theatre. Official syllabus topics are not skipped; they do not get a 3-day PPT.

**Immediate preparation** (NEET plan): do not touch the whole syllabus. Run this loop on the current phase topic (Respiration / remaining Plant Physiology, then Human Physiology as already sequenced).

## Tutor operating loop (one Priority-1 topic)

```text
Visual module (P1 PPT / long video)
        → Live class or YouTube long
        → Same-day DPP (must solve)
        → Same-week mock or PYQ + analysis
        → Optional 10-min backlog (paid cohort only)
```

1. **Day of publish / class.** Visual lesson (PPT / long video) + Warm-up 4 / Sprint 8 / Race 4 items.
2. **Same calendar day.** DPP 10–15 items that *must* be solved; optional 15–20 min DPP-solve video.
3. **Same week.** Chapter test or PYQ set + a short analysis.
4. **If a live batch exists.** WAVE-lite checks every few minutes; doubts in a *logged* place. WhatsApp is overflow.
5. **If a paid cohort exists.** Fortnight 8-min mentor on skipped DPPs/tests, not content.

Student day that is *in scope* for you: evening live or YouTube + same-night DPP + Sunday (or weekly) mock + analysis. School period, tablet lesson, and 8-hour doubt counters are **out of scope** unless you later sell into schools.

## Limits (do not hide)

- Toppr-quality **adaptive next question** needs attempt-history infrastructure. Until then, tagging on the key is the steal.
- Parallel TAs and 8-hour doubt desks are **org**, not a checklist item.
- Pair-compare numbers in the HTML stay directional. Verify any one feature against the live SKU before citing it publicly.
- A “best of all” student day that stacks school period + WAVE + DPP + mentor is pedagogically dense and operationally impossible for one faculty. Do not run that stack.
- This file is an operating filter. The master topic order, Priority 1/2/3, and “do not start PPTs randomly” remain in [NEET-preparation-strategies.md](NEET-preparation-strategies.md).
