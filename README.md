# Tutor

NEET Biology teaching plan plus how a solo faculty runs a week — filtered from Indian edtech operating models, not from marketing.

**Spine:** one Biology teacher, PPT 2–3 days per Priority-1 topic, YouTube + online classes. Closest product type: coaching loop + visual lesson + same-day practice. Not a school LMS.

---

## How to read these files

Do not read everything cover to cover. Use this order.

### 1. Glossary (about 10 minutes)

Open [tutor-operating-loop.md](tutor-operating-loop.md) and read only **Abbreviation glossary**. DPP, OS, WAVE, TLA, AITS, SKU, and the rest are defined there. Leave it open as a dictionary.

### 2. Work plan (the spine)

[NEET-preparation-strategies.md](NEET-preparation-strategies.md) is what you follow when preparing yourself and making materials.

Read in this order:

1. Section 1 — core strategies (do not skip)
2. Section 2 — four phases (you are in Plant Physiology / Respiration; Circulation is already done)
3. Class 11 topics, then Class 12 — by **priority**, not chapter number
4. Priority-1 **content package** (one topic = PPT + long video + shorts + PYQ + worksheet + test)

If another file disagrees on *what to teach or in what order*, this file wins.

Official syllabus checklist: **NMC / NTA NEET (UG) 2026**.

### 3. Week timing (overlay)

Finish [tutor-operating-loop.md](tutor-operating-loop.md): keep vs refuse, then the operating loop. It does **not** rewrite the NEET strategies. It only adds **when** assets fire:

- same calendar day: DPP that must be solved
- same week: chapter test or PYQ + analysis
- live batch only: short checks every few minutes
- paid cohort only: 8-minute backlog on skipped work

### 4. Platform encyclopedia (reference)

[indian-edtech-platform-comparison.md](indian-edtech-platform-comparison.md) is long. Use it when you need one platform’s teacher/student day, or the rule: do not mix school OS, coaching OS, practice OS, and visual library into one faculty role.

Do not read it as a to-do list.

### 5. Interactive comparison

Open [edtech-cross-platform-comparison.html](edtech-cross-platform-comparison.html) in a browser (double-click, or any local static server).

| View | Use it for |
|---|---|
| 1. Pair compare | Two platforms side by side |
| 2. Capability matrix | Who is strong at which job |
| 3–4. Student / teacher day | Day-to-day loop |
| 5. Job fit | Which spine matches the job |
| 6. Steal sheet | Full “best of all” stack (includes school/hybrid) |
| **7. Tutor filter** | Same filter as the operating-loop file — your job |

Pair scores are expert ordinals (1–5), not product telemetry. Verify a feature against the live SKU before citing it publicly.
