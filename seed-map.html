How to load

Wipe Postgres, then seed

docker compose up -d postgres
cd backend
python -m app.seed_cli --reset

--reset drops every table and recreates them. Restart FastAPI after wipe if it was running. pytest still uses in-memory SQLite and seeds the same pack per test.
