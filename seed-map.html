Arm of the snowflake

Catalog seed map

One row per catalog screen. Tags are the last 12 digits of cccccccc-0001-… (exam-prep). Language uses 0002, music 0003. Same pack in every tenant. OTP is always 000000. Wipe: cd backend; python -m app.seed_cli --reset.

This pack is built for state contrast, not one happy path: recorded vs upcoming vs no-video sessions; graded vs ungraded homework; 1/2 vs 0/2 practice and a 2/2 test; accepted vs pending parent link; enrolled vs unenrolled student; enabled vs disabled automation; open vs paid invoices; parent cannot see student-2 fees or threads until they accept link-exam-prep-pending.
Join → enter writes or updates attendance (platform truth, not the Meet URL). Seed session …022 already has present/absent so you can contrast a clean enter on join-exam-prep-next. Transcript stays empty. 005 also seeds historical week bars. No live vendors.

How to load

Wipe Postgres, then seed

docker compose up -d postgres
cd backend
python -m app.seed_cli --reset

--reset drops every table and recreates them. Restart FastAPI after wipe if it was running. pytest still uses in-memory SQLite and seeds the same pack per test.
