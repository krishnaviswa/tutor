encodes · rule 4 — analytics without a remedial action is a PDF nobody uses

The filter every screen was held to

Copied from the operating loop. A screen only ships if it survives all five — and if it does not appear on the refuse list.

1

Layer four spines. School, coaching, practice and visual library can share a login later — not one faculty role now.

2

Star faculty is not the homework policeman. A mentor backlog slot chases skipped work. The lecture never does.

3

Live without a same-day artefact is webinar theatre. A DPP on the same calendar day, or the class does not ship.

4

Analytics without a remedial action is a PDF nobody uses. Every miss becomes a tag, a clip, or a backlog item.

5

WhatsApp / Telegram is overflow — never the system of record for notes, tests, or doubts.

Copy the behaviour, not the org.

Refused for now, and not designed: a school timetable / attendance OS · a scan-grade paper factory · a full go-live incentive-and-penalty dashboard · 8-hour subject-wise doubt counters · a parent attendance OS · offline tablet lesson packs · a two-teacher studio hall.
