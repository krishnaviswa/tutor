Technical map

How it is built

Layered monolith. Next.js holds no business rules. Routers never call vendors. Services never know HTTP. 33 APIs sim (002), 51 planned (003). 37 catalog entities. 38 modules. 8 ports.

Entry (JWT sub + role + workspace_id)
  → Next.js 15 App Router (catalog routes only)
  → FastAPI /api/v1
  → CORS → request id → tenant → authn → authz + G1 → QuotaGuard → idempotency → audit
  → Services (Record, Timeline, Quota, Notify, + 003 domains)
  → Ports (mock | storage local)
  → SQLAlchemy → SQLite file | optional Postgres

002 code that 003 must not break

  • backend/app/factory.py — mock-only providers enforced
  • backend/app/models/tables.py — spine + meters
  • backend/app/api/v1/ — auth, workspaces, students, cohorts, parent, sessions, owner, stubs
  • backend/app/services/ — auth, record, timeline, quota, notify, seed
  • backend/tests/ — isolation, record→timeline, quotas/RBAC, parent, live_calls==0

Protected tests

Phase gate: cd backend; pytest. Isolation A vs B, PATCH record fans out timeline in A only, parent cannot see unlinked child, quota 80/100 without disabling D4/F2, no live vendor calls, no /sim/login.
